รายละเอียดเชิงเทคนิค

1. ภาพรวมและวัตถุประสงค์

  • พัฒนาระบบตรวจจับการเปิด-ปิดฝา ประตู หรือกล่อง [cite: 2]
  • ประยุกต์ใช้เซนเซอร์ KY-021 ร่วมกับบอร์ดไมโครคอนโทรลเลอร์ (เช่น Arduino UNO R3) [cite: 2]
  • ตรวจสอบว่าวัตถุอยู่ในสถานะ "เปิด" (ON) หรือ "ปิด" (OFF) พร้อมแสดงผลสถานะและสถิติพื้นฐานผ่านหน้าจอ LCD 16x2 [cite: 2]

2. อุปกรณ์ที่ใช้งาน

  • บอร์ดไมโครคอนโทรลเลอร์: Arduino UNO R3 (ใช้ชิป ATmega328P) [cite: 2]
  • เซนเซอร์ตรวจจับ: โมดูล KY-021 Mini Reed Switch Module [cite: 2]
  • จอแสดงผล: จอ LCD 16x2 พร้อมโมดูล I2C [cite: 2]

3. การต่อวงจร (Wiring)

  • โมดูล KY-021: ขา Signal ต่อเข้ากับขา D7, VCC ต่อเข้ากับ 5V, และ GND ต่อเข้ากับ GND [cite: 2]
  • จอ LCD 16x2 (ผ่าน I2C): ใช้ขา A4 สำหรับเชื่อมต่อ SDA, A5 สำหรับเชื่อมต่อ SCL และ Address คือ 0x27 [cite: 2]

4. รูปแบบการแสดงผล (UX บน LCD)

  • บรรทัดที่ 0: แสดงสถานะปัจจุบัน เช่น OPEN หรือ CLOSED [cite: 2]
  • บรรทัดที่ 1: แสดงจำนวนครั้ง (Count: XXXX) ที่สถานะมีการเปลี่ยนแปลง หรือเวลาล่าสุด [cite: 2]

การพัฒนาและการทดสอบ

5. ความท้าทายและข้อควรระวัง

  • ต้องตรวจสอบสถานะ HIGH/LOW ผ่าน Serial Monitor ก่อนเขียนเงื่อนไข OPEN/CLOSED [cite: 2]
  • แก้ปัญหาสัญญาณแกว่ง (Bounce) โดยเขียนโปรแกรม Debounce ยืนยันสถานะคงที่อย่างน้อย 30–50ms [cite: 2]
  • ควรอัปเดตหน้าจอ LCD เฉพาะตอนสถานะเปลี่ยน และเติมช่องว่าง (Padding) ให้เต็ม 16 ตัวอักษรเพื่อลดจอกระพริบ [cite: 2]
  • หลีกเลี่ยงการต่อขา D0 และ D1 หากไม่จำเป็น [cite: 2]

6. การทดสอบและเกณฑ์การยอมรับ

  • ทดสอบโดยนำแม่เหล็กเข้า-ออก และตรวจสอบว่าหน้าจอ LCD แสดงข้อความเปลี่ยนแปลงได้รวดเร็วและถูกต้อง [cite: 2]
  • ค่า Count ต้องไม่เด้งนับซ้ำจากปัญหา Bounce (ตัวเลขเพิ่มตามจำนวนที่ตั้งใจเปิด-ปิดเท่านั้น) [cite: 2]
  • หน้าจอ LCD อ่านง่าย ไม่เกิดอาการกระพริบ และการต่อสายวงจรถูกต้อง 100% [cite: 2]
