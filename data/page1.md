# โครงงานระบบตรวจจับประตูเปิด-ปิด (Door/Open Sensor Project)

## 1. ภาพรวมและวัตถุประสงค์
โครงงานนี้เป็นการพัฒนาระบบตรวจจับการเปิด-ปิดฝา ประตู หรือกล่อง โดยประยุกต์ใช้เซนเซอร์ KY-021 ร่วมกับบอร์ดไมโครคอนโทรลเลอร์ (เช่น Arduino UNO R3) เพื่อใช้ตรวจสอบว่าวัตถุอยู่ในสถานะ "เปิด" (OPEN) หรือ "ปิด" (CLOSED) พร้อมแสดงผลสถานะและสถิติพื้นฐานผ่านหน้าจอ LCD 16x2

## 2. อุปกรณ์ที่ใช้งาน
- **บอร์ดไมโครคอนโทรลเลอร์:** Arduino UNO R3 (ใช้ชิป ATmega328P) เหมาะสำหรับงานต้นแบบ มีทั้งขา Digital I/O, Analog Input และพอร์ตต่างๆ สำหรับเชื่อมต่อเซนเซอร์
- **เซนเซอร์ตรวจจับ:** โมดูล KY-021 Mini Reed Switch Module
- **จอแสดงผล:** จอ LCD 16x2 พร้อมโมดูล I2C

## 3. การต่อวงจร (Wiring)
อ้างอิงการเชื่อมต่อตามข้อมูลที่ระบุ ดังนี้:

- **โมดูล I2C:**
  - ใช้ขา `A4` สำหรับเชื่อมต่อ SDA
  - ใช้ขา `A5` สำหรับเชื่อมต่อ SCL

- **โมดูล KY-021 (Mini Reed Switch Module):**
  - ขา `Signal` ==> ต่อเข้ากับขา `D7`
  - ขา `VCC` ==> ต่อเข้ากับ `5V` (จ่ายไฟเลี้ยง)
  - ขา `GND` ==> ต่อเข้ากับ `GND`

- **จอ LCD 16x2 (ผ่าน I2C):**
  - `A4` -> I2C SDA
  - `A5` -> I2C SCL
  - Address LCD --> `0x27`

## 4. รูปแบบการแสดงผลบนหน้าจอ (UX บน LCD)
หน้าจอ LCD 16x2 จะถูกออกแบบให้แสดงผลเพื่อให้ผู้ใช้งานอ่านได้ง่าย:
- **บรรทัดที่ 0:** แสดงสถานะปัจจุบัน เช่น `OPEN` หรือ `CLOSED`
- **บรรทัดที่ 1:** แสดงจำนวนครั้ง (Count) ที่สถานะมีการเปลี่ยนแปลง ตัวอย่างเช่น `Count: XXXX` หรืออาจประยุกต์แสดงเวลาล่าสุด (`Last: ON hh:mm:ss`)

## 5. ความท้าทายและข้อควรระวังในการพัฒนา
เพื่อให้ระบบสามารถนำไปใช้งานได้จริง จะต้องจัดการกับเงื่อนไขต่อไปนี้:
- **สถานะ HIGH/LOW ที่อาจกลับกัน:** จำเป็นต้องตรวจสอบผ่าน Serial Monitor ก่อนว่า เมื่อนำแม่เหล็กเข้าใกล้ เซนเซอร์จะส่งค่าเป็น HIGH หรือ LOW เพื่อนำไปเขียนเงื่อนไข OPEN/CLOSED ในโปรแกรมให้ถูกต้อง
- **ปัญหาสัญญาณแกว่ง (Bounce):** หน้าสัมผัสของ Reed switch อาจเกิดการแกว่ง ต้องมีการเขียนโปรแกรม Debounce (เช่น ยืนยันว่าสถานะคงที่อย่างน้อย 30–50ms) และให้นับ Event เฉพาะตอนที่สถานะ "เปลี่ยนจริง" (Edge-trigger) เท่านั้น
- **การรีเฟรชหน้าจอ LCD:** 
  - ควรอัปเดต (Refresh) หน้าจอเฉพาะตอนที่สถานะมีการเปลี่ยนแปลงเพื่อลดอาการจอกระพริบ
  - ในการพิมพ์ข้อความแต่ละครั้ง ควรเติมช่องว่าง (Padding) ให้เต็ม 16 ตัวอักษรเสมอเพื่อเคลียร์ข้อความเก่า
- **ข้อควรระวังในการต่อบอร์ด:** ควรตรวจสอบแรงดันไฟก่อนต่ออุปกรณ์เสมอ และหลีกเลี่ยงการต่อขา D0 และ D1 หากไม่จำเป็น เพราะสงวนไว้สำหรับการสื่อสาร Serial

## 6. วิธีการทดสอบและเกณฑ์การยอมรับ (Acceptance Criteria)

**วิธีการทดสอบระบบต้นแบบ:**
1. เปิด Serial Monitor เพื่อตรวจดูค่า Digital แบบ Raw Value ที่อ่านได้จากเซนเซอร์
2. นำแม่เหล็กเข้าและออกจากตำแหน่งเซนเซอร์เดิมซ้ำๆ 
3. สังเกตการณ์บนหน้าจอ LCD ว่าข้อความ OPEN/CLOSED เปลี่ยนแปลงอย่างรวดเร็วและถูกต้องหรือไม่ รวมถึงตัวนับ (Count) ต้องเพิ่มแค่ครั้งละ 1 Event

**เกณฑ์การยอมรับ (Acceptance Criteria):**
- ค่า Count ไม่เด้งนับซ้ำจากปัญหา Bounce (ตัวเลขต้องเพิ่มตามจำนวนรอบที่ตั้งใจเปิด-ปิดเท่านั้น)
- หน้าจอ LCD อ่านง่าย ไม่เกิดอาการกระพริบระหว่างทำงาน
- การต่อสายวงจร (Wiring) ถูกต้อง 100% (KY-021 Signal ที่ D7 และ LCD I2C Address 0x27 เชื่อมต่อ SDA เข้า A4, SCL เข้า A5)
